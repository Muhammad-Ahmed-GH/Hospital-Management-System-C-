# Hospital Management System (CLI)

A command-line interface (CLI) Hospital Management System developed in C programming language. This project was initially created by a team and is now being further developed and maintained.

## Features

- Patient Management
- Doctor Management
- Appointment Scheduling
- Medical Records
- Billing System
- User Authentication

## Usage

Run the program:
```bash
./hospital_management_system
```

Follow the on-screen instructions to navigate through the system.

## Project Structure

- `src/` - Source code files
- `include/` - Header files
- `data/` - Data storage files
- `Makefile` - Build configuration
